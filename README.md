# Museum Study Lab

GCT583 강의자료 12개를 바탕으로 만든 영어 퀴즈입니다. 객관식 20문제와 서술형 5문제가 한 세트이며, 서술형은 한·영 키워드 기준으로 피드백을 제공합니다. 진행 상황과 오답 노트는 현재 브라우저와 사이트 주소에 저장됩니다.

## GitHub Pages 배포

1. ZIP 압축을 풉니다.
2. GitHub 저장소를 만든 뒤 압축을 푼 파일을 저장소 최상단에 올립니다. `index.html`이 최상단에 있어야 합니다.
3. 저장소의 **Settings → Pages**로 이동합니다. **Source**에서 **Deploy from a branch**를 선택합니다.
4. **main**과 **/ (root)**를 선택하고 **Save**를 누릅니다.
5. 배포 후 **Settings → Pages**에 표시되는 주소로 접속합니다.

별도 빌드나 API 키가 필요 없습니다. 로컬에서는 `index.html`을 브라우저에서 열 수 있습니다.

## 강의자료와 공개 범위

원본 PDF는 암호화된 조각으로 `lectures/`에 포함됩니다. 사이트의 **강의자료** 탭에서 비밀번호를 입력하면 브라우저가 원본 PDF를 복원해 다운로드합니다. GitHub Pages의 HTTPS 주소에서 사용하세요. 공개 저장소에서는 암호화 파일을 누구나 복사하고 오프라인으로 비밀번호를 추측할 수 있습니다. 문항과 정답 및 강의 인용문도 공개됩니다. 원본 비밀번호는 소스에 포함되지 않습니다.


일부 해설의 학습 도식은 `images/` 폴더에 있습니다. 배포할 때 폴더 구조를 유지하세요.

## 암호화된 PDF 추가

사이트 ZIP과 `Museum_Lecture_PDFs_1.zip`부터 `Museum_Lecture_PDFs_4.zip`까지 같은 폴더에 풉니다. 네 ZIP에 들어 있는 `lectures/` 폴더를 하나로 합쳐 `index.html` 옆에 둡니다. PDF 조각과 사이트 파일을 모두 커밋하고 Git으로 푸시하세요. 조각 하나는 16 MiB 정도이며 전체 자료는 약 790 MiB입니다. PDF 다운로드는 HTTPS로 배포된 사이트에서 테스트하세요.
