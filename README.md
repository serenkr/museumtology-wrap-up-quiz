# Museum Study Lab

GCT583 강의자료 12개를 바탕으로 만든 영어 퀴즈입니다. 객관식 20문제와 서술형 5문제가 한 세트이며, 서술형은 한·영 키워드 기준으로 피드백을 제공합니다. 진행 상황과 오답 노트는 현재 브라우저와 사이트 주소에 저장됩니다.

## GitHub Pages 배포

1. ZIP 압축을 풉니다.
2. GitHub 저장소를 만든 뒤 압축을 푼 파일을 저장소 최상단에 올립니다. `index.html`이 최상단에 있어야 합니다.
3. 저장소의 **Settings → Pages**로 이동합니다. **Source**에서 **Deploy from a branch**를 선택합니다.
4. **main**과 **/ (root)**를 선택하고 **Save**를 누릅니다.
5. 배포 후 **Settings → Pages**에 표시되는 주소로 접속합니다.

별도 빌드나 API 키가 필요 없습니다. 로컬에서는 `index.html`을 브라우저에서 열 수 있습니다.

## 강의자료와 공개 범위

원본 PDF는 포함하지 않았습니다. 해설에는 자료명, 페이지 번호, 강의자료 인용문이 포함됩니다. 자료 링크는 원본에 접근 권한이 있는 계정에서만 열립니다. 공개 저장소에 올리면 문항, 정답, 해설과 인용문이 담긴 `bank.js`도 공개되므로 강의자료 인용의 공개 가능 여부를 먼저 확인하세요.


일부 해설의 학습 도식은 `images/` 폴더에 있습니다. 배포할 때 폴더 구조를 유지하세요.
